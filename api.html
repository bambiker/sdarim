מסדירים

חוזרים לחלוקת התנ"ך היהודית





החלוקה לתנ"ך לסדרים זמינה גם דרך אתר מסדירים www.masdirim.org באמצעות הממשק למשתמש,  וניתן לגשת למידע גם באמצעות API וקבצי JSON. קובץ JSON המלא המכיל את כל פסוקי התנ"ך זמין להורדה בכתובת:
https://raw.githubusercontent.com/bambiker/sdarim/refs/heads/main/sdarim.json
ניתן דרך API לגשת לכל פסוק בנפרד לפי החלוקה לפרקים בכתובת:
https://raw.githubusercontent.com/bambiker/sdarim/refs/heads/main/API/chapter_פסוק_פרק_ספר.json
לדוגמה, עבור ספר דברי הימים א', פרק ב', פסוק ג' (לפי החלוקה לפרקים)
https://raw.githubusercontent.com/bambiker/sdarim/refs/heads/main/API/chapter_ג_ב_דברי_הימים_א.json
ניתן גם לא לציין את הפסוק ואז לקבל את כל הפסוקים בפרק, לדוגמא
https://raw.githubusercontent.com/bambiker/sdarim/refs/heads/main/API/chapter_ב_דברי_הימים_א.json
בנוסף, ניתן לגשת גם לפי החלוקה לסדרים בכתובת
https://raw.githubusercontent.com/bambiker/sdarim/refs/heads/main/API/seder_פסוק_פרק_סדר.json

}


כאשר bookchapter הוא שם הספר לפי החלוקה לפרקים
chapter הוא מספר הפרק
versechapter הוא מספר הפסוק לפי החלוקה לפרקים
bookseder הוא שם הספר לפי החלוקה לסדרים
seder הוא מספר הסדר
verseseder הוא מספר הפסוק לפי החלוקה לסדרים
versenikud הוא הפסוק כולל ניקוד וטעמים
versenonikud הוא הפסוק ללא ניקוד וללא טעמים

רשימת כל הסדרים

קובץ אחד קטן עם כל 447 הסדרים: היכן כל סדר מתחיל ונגמר לפי החלוקה לפרקים, כמה פסוקים יש בו ובאילו פרשות הוא נמצא. מתאים ללוחות לימוד, לאפליקציות ולכל מי שצריך לדעת את גבולות הסדרים בלי להוריד את הטקסט.
https://raw.githubusercontent.com/bambiker/sdarim/refs/heads/main/API/sedarim.json
כל סדר נראה כך (בראשית סדר יג):
{
    "book": "בראשית",
    "seder": "יג",
    "seder_number": 13,
    "start": {"book": "בראשית", "chapter": "טז", "verse": "א", "chapter_number": 16, "verse_number": 1},
    "end": {"book": "בראשית", "chapter": "טז", "verse": "טז", "chapter_number": 16, "verse_number": 16},
    "verses": 16,
    "parashot": ["לך לך"]
}
book הוא שם הספר לפי החלוקה לסדרים, seder ו-seder_number הם מספר הסדר באותיות ובמספר, start ו-end הם הפסוק הראשון והאחרון בסדר לפי החלוקה לפרקים (שם הספר, הפרק והפסוק באותיות ובמספרים), verses הוא מספר הפסוקים בסדר, ו-parashot הן הפרשות שהסדר נמצא בהן (בתורה בלבד).

טבלת המרה בין פרקים לסדרים

המיקום של כל פסוק בתנ"ך גם לפי הפרקים וגם לפי הסדרים, בלי הטקסט. הקובץ קטן פי 10 מהקובץ המלא, ומתאים לאתר שרוצה להמיר הפניות מפרקים לסדרים בעצמו.
https://raw.githubusercontent.com/bambiker/sdarim/refs/heads/main/API/map.json
כל שורה ב-verses היא פסוק אחד, לפי הסדר של השדות ב-fields:
{"fields":["bookchapter","chapter","versechapter","bookseder","seder","verseseder"],
"verses":[
["בראשית","א","א","בראשית","א","א"],
["בראשית","א","ב","בראשית","א","ב"],
...]}

דוגמאות קוד

אפשר לקרוא את כל הקבצים ישירות מהדפדפן של אתר אחר (השרת מאפשר זאת), בלי שרת ביניים.
המרת פסוק מפרקים לסדרים ב-JavaScript:
const res = await fetch('https://raw.githubusercontent.com/bambiker/sdarim/refs/heads/main/API/map.json');
const map = await res.json();
// בראשית פרק טז פסוק א
const row = map.verses.find(v => v[0] == 'בראשית' && v[1] == 'טז' && v[2] == 'א');
console.log(row[3] + ' סדר ' + row[4] + ' פסוק ' + row[5]);   // בראשית סדר יג פסוק א
הצגת תחילת כל סדר בספר שמואל ב-Python:
import requests

sedarim = requests.get('https://raw.githubusercontent.com/bambiker/sdarim/refs/heads/main/API/sedarim.json').json()
for s in sedarim:
    if s['book'] == 'שמואל':
        print(s['seder'], s['start']['book'], s['start']['chapter_number'], s['start']['verse_number'])
# א שמואל א 1 1
# ב שמואל א 2 10
# ...

כשאתם מציגים מידע מהאתר, נשמח לקרדיט בנוסח: "החלוקה לסדרים: מסדירים, www.masdirim.org".

המידע הזה ניתן לשימוש חופשי, הן עבור תוכנה והן עבור שימוש מסחרי. נשמח אם תציינו שאתר מסדירים הוא המקור לנתונים.
