יהושע סדר יב

פתיחה באתר · ספר יהושע כולו ·

(א) אֵ֣לֶּה הַנְּחָלֹ֡ת אֲשֶׁ֣ר נִחֲל֣וּ אֶלְעָזָ֣ר הַכֹּהֵ֣ן ׀ וִיהוֹשֻׁ֪עַ בִּן־ נ֟וּן וְרָאשֵׁ֣י הָֽאָב֣וֹת לְמַטּוֹת֩ בְּנֵי־ יִשְׂרָאֵ֨ל ׀ בְּגוֹרָ֤ל ׀ בְּשִׁלֹה֙ לִפְנֵ֣י יְהוָ֔ה פֶּ֖תַח אֹ֣הֶל מוֹעֵ֑ד וַיְכַלּ֕וּ מֵֽחַלֵּ֖ק אֶת־ הָאָֽרֶץ׃ (ב) וַיְדַבֵּ֣ר יְהוָ֔ה אֶל־ יְהוֹשֻׁ֖עַ לֵאמֹֽר׃ (ג) דַּבֵּ֛ר אֶל־ בְּנֵ֥י יִשְׂרָאֵ֖ל לֵאמֹ֑ר תְּנ֤וּ לָכֶם֙ אֶת־ עָרֵ֣י הַמִּקְלָ֔ט אֲשֶׁר־ דִּבַּ֥רְתִּי אֲלֵיכֶ֖ם בְּיַד־ מֹשֶֽׁה׃ (ד) לָנ֥וּס שָׁ֙מָּה֙ רוֹצֵ֔חַ מַכֵּה־ נֶ֥פֶשׁ בִּשְׁגָגָ֖ה בִּבְלִי־ דָ֑עַת וְהָי֤וּ לָכֶם֙ לְמִקְלָ֔ט מִגֹּאֵ֖ל הַדָּֽם׃ (ה) וְנָ֞ס אֶל־ אַחַ֣ת ׀ מֵהֶעָרִ֣ים הָאֵ֗לֶּה וְעָמַד֙ פֶּ֚תַח שַׁ֣עַר הָעִ֔יר וְדִבֶּ֛ר בְּאָזְנֵ֛י זִקְנֵ֥י־ הָעִֽיר הַהִ֖יא אֶת־ דְּבָרָ֑יו וְאָסְפ֨וּ אֹת֤וֹ הָעִ֙ירָה֙ אֲלֵיהֶ֔ם וְנָתְנוּ־ ל֥וֹ מָק֖וֹם וְיָשַׁ֥ב עִמָּֽם׃ (ו) וְכִ֨י יִרְדֹּ֜ף גֹּאֵ֤ל הַדָּם֙ אַֽחֲרָ֔יו וְלֹֽא־ יַסְגִּ֥רוּ אֶת־ הָרֹצֵ֖חַ בְּיָד֑וֹ כִּ֤י בִבְלִי־ דַ֙עַת֙ הִכָּ֣ה אֶת־ רֵעֵ֔הוּ וְלֹֽא־ שֹׂנֵ֥א ה֛וּא ל֖וֹ מִתְּמ֥וֹל שִׁלְשֽׁוֹם׃ (ז) וְיָשַׁ֣ב ׀ בָּעִ֣יר הַהִ֗יא עַד־ עָמְד֞וֹ לִפְנֵ֤י הָֽעֵדָה֙ לַמִּשְׁפָּ֔ט עַד־ מוֹת֙ הַכֹּהֵ֣ן הַגָּד֔וֹל אֲשֶׁ֥ר יִהְיֶ֖ה בַּיָּמִ֣ים הָהֵ֑ם אָ֣ז ׀ יָשׁ֣וּב הָרוֹצֵ֗חַ וּבָ֤א אֶל־ עִירוֹ֙ וְאֶל־ בֵּית֔וֹ אֶל־ הָעִ֖יר אֲשֶׁר־ נָ֥ס מִשָּֽׁם׃ (ח) וַיַּקְדִּ֜שׁוּ אֶת־ קֶ֤דֶשׁ בַּגָּלִיל֙ בְּהַ֣ר נַפְתָּלִ֔י וְאֶת־ שְׁכֶ֖ם בְּהַ֣ר אֶפְרָ֑יִם וְאֶת־ קִרְיַ֥ת אַרְבַּ֛ע הִ֥יא חֶבְר֖וֹן בְּהַ֥ר יְהוּדָֽה׃ (ט) וּמֵעֵ֜בֶר לְיַרְדֵּ֤ן יְרִיחוֹ֙ מִזְרָ֔חָה נָתְנ֞וּ אֶת־ בֶּ֧צֶר בַּמִּדְבָּ֛ר בַּמִּישֹׁ֖ר מִמַּטֵּ֣ה רְאוּבֵ֑ן וְאֶת־ רָאמֹ֤ת בַּגִּלְעָד֙ מִמַּטֵּה־ גָ֔ד וְאֶת־ (גלון) גּוֹלָ֥ן בַּבָּשָׁ֖ן מִמַּטֵּ֥ה מְנַשֶּֽׁה׃ (י) אֵ֣לֶּה הָיוּ֩ עָרֵ֨י הַמּֽוּעָדָ֜ה לְכֹ֣ל ׀ בְּנֵ֣י יִשְׂרָאֵ֗ל וְלַגֵּר֙ הַגָּ֣ר בְּתוֹכָ֔ם לָנ֣וּס שָׁ֔מָּה כָּל־ מַכֵּה־ נֶ֖פֶשׁ בִּשְׁגָגָ֑ה וְלֹ֣א יָמ֗וּת בְּיַד֙ גֹּאֵ֣ל הַדָּ֔ם עַד־ עָמְד֖וֹ לִפְנֵ֥י הָעֵדָֽה׃ (יא) וַֽיִּגְּשׁ֗וּ רָאשֵׁי֙ אֲב֣וֹת הַלְוִיִּ֔ם אֶל־ אֶלְעָזָר֙ הַכֹּהֵ֔ן וְאֶל־ יְהוֹשֻׁ֖עַ בִּן־ נ֑וּן וְאֶל־ רָאשֵׁ֛י אֲב֥וֹת הַמַּטּ֖וֹת לִבְנֵ֥י יִשְׂרָאֵֽל׃ (יב) וַיְדַבְּר֨וּ אֲלֵיהֶ֜ם בְּשִׁלֹ֗ה בְּאֶ֤רֶץ כְּנַ֙עַן֙ לֵאמֹ֔ר יְהוָה֙ צִוָּ֣ה בְיַד־ מֹשֶׁ֔ה לָֽתֶת־ לָ֥נוּ עָרִ֖ים לָשָׁ֑בֶת וּמִגְרְשֵׁיהֶ֖ן לִבְהֶמְתֵּֽנוּ׃ (יג) וַיִּתְּנ֨וּ בְנֵי־ יִשְׂרָאֵ֧ל לַלְוִיִּ֛ם מִנַּחֲלָתָ֖ם אֶל־ פִּ֣י יְהוָ֑ה אֶת־ הֶעָרִ֥ים הָאֵ֖לֶּה וְאֶת־ מִגְרְשֵׁיהֶֽן׃ (יד) וַיֵּצֵ֥א הַגּוֹרָ֖ל לְמִשְׁפְּחֹ֣ת הַקְּהָתִ֑י וַיְהִ֡י לִבְנֵי֩ אַהֲרֹ֨ן הַכֹּהֵ֜ן מִן־ הַלְוִיִּ֗ם מִמַּטֵּ֣ה יְ֠הוּדָה וּמִמַּטֵּ֨ה הַשִּׁמְעֹנִ֜י וּמִמַּטֵּ֤ה בִנְיָמִן֙ בַּגּוֹרָ֔ל עָרִ֖ים שְׁלֹ֥שׁ עֶשְׂרֵֽה׃ (טו) וְלִבְנֵ֨י קְהָ֜ת הַנּוֹתָרִ֗ים מִמִּשְׁפְּחֹ֣ת מַטֵּֽה־ אֶ֠פְרַיִם וּֽמִמַּטֵּה־ דָ֞ן וּמֵחֲצִ֨י מַטֵּ֧ה מְנַשֶּׁ֛ה בַּגּוֹרָ֖ל עָרִ֥ים עָֽשֶׂר׃ (טז) וְלִבְנֵ֣י גֵרְשׁ֗וֹן מִמִּשְׁפְּח֣וֹת מַטֵּֽה־ יִשָּׂשכָ֣ר וּמִמַּטֵּֽה־ אָ֠שֵׁר וּמִמַּטֵּ֨ה נַפְתָּלִ֜י וּ֠מֵחֲצִי מַטֵּ֨ה מְנַשֶּׁ֤ה בַבָּשָׁן֙ בַּגּוֹרָ֔ל עָרִ֖ים שְׁלֹ֥שׁ עֶשְׂרֵֽה׃ (יז) לִבְנֵ֨י מְרָרִ֜י לְמִשְׁפְּחֹתָ֗ם מִמַּטֵּ֨ה רְאוּבֵ֤ן וּמִמַּטֵּה־ גָד֙ וּמִמַּטֵּ֣ה זְבוּלֻ֔ן עָרִ֖ים שְׁתֵּ֥ים עֶשְׂרֵֽה׃ (יח) וַיִּתְּנ֤וּ בְנֵֽי־ יִשְׂרָאֵל֙ לַלְוִיִּ֔ם אֶת־ הֶעָרִ֥ים הָאֵ֖לֶּה וְאֶת־ מִגְרְשֵׁיהֶ֑ן כַּאֲשֶׁ֨ר צִוָּ֧ה יְהוָ֛ה בְּיַד־ מֹשֶׁ֖ה בַּגּוֹרָֽל׃ (יט) וַֽיִּתְּנ֗וּ מִמַּטֵּה֙ בְּנֵ֣י יְהוּדָ֔ה וּמִמַּטֵּ֖ה בְּנֵ֣י שִׁמְע֑וֹן אֵ֚ת הֶֽעָרִ֣ים הָאֵ֔לֶּה אֲשֶׁר־ יִקְרָ֥א אֶתְהֶ֖ן בְּשֵֽׁם׃ (כ) וַֽיְהִי֙ לִבְנֵ֣י אַהֲרֹ֔ן מִמִּשְׁפְּח֥וֹת הַקְּהָתִ֖י מִבְּנֵ֣י לֵוִ֑י כִּ֥י לָהֶ֛ם הָיָ֥ה הַגּוֹרָ֖ל רִיאשֹׁנָֽה׃ (כא) וַיִּתְּנ֨וּ לָהֶ֜ם אֶת־ קִרְיַת֩ אַרְבַּ֨ע אֲבִ֧י הָֽעֲנ֛וֹק הִ֥יא חֶבְר֖וֹן בְּהַ֣ר יְהוּדָ֑ה וְאֶת־ מִגְרָשֶׁ֖הָ סְבִיבֹתֶֽיהָ׃ (כב) וְאֶת־ שְׂדֵ֥ה הָעִ֖יר וְאֶת־ חֲצֵרֶ֑יהָ נָֽתְנ֛וּ לְכָלֵ֥ב בֶּן־ יְפֻנֶּ֖ה בַּאֲחֻזָּתֽוֹ׃ (כג) וְלִבְנֵ֣י ׀ אַהֲרֹ֣ן הַכֹּהֵ֗ן נָֽתְנוּ֙ אֶת־ עִיר֙ מִקְלַ֣ט הָרֹצֵ֔חַ אֶת־ חֶבְר֖וֹן וְאֶת־ מִגְרָשֶׁ֑הָ וְאֶת־ לִבְנָ֖ה וְאֶת־ מִגְרָשֶֽׁהָ׃ (כד) וְאֶת־ יַתִּר֙ וְאֶת־ מִגְרָשֶׁ֔הָ וְאֶת־ אֶשְׁתְּמֹ֖עַ וְאֶת־ מִגְרָשֶֽׁהָ׃ (כה) וְאֶת־ חֹלֹן֙ וְאֶת־ מִגְרָשֶׁ֔הָ וְאֶת־ דְּבִ֖ר וְאֶת־ מִגְרָשֶֽׁהָ׃ (כו) וְאֶת־ עַ֣יִן וְאֶת־ מִגְרָשֶׁ֗הָ וְאֶת־ יֻטָּה֙ וְאֶת־ מִגְרָשֶׁ֔הָ אֶת־ בֵּ֥ית שֶׁ֖מֶשׁ וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֣ים תֵּ֔שַׁע מֵאֵ֕ת שְׁנֵ֥י הַשְּׁבָטִ֖ים הָאֵֽלֶּה׃ (כז) וּמִמַּטֵּ֣ה בִנְיָמִ֔ן אֶת־ גִּבְע֖וֹן וְאֶת־ מִגְרָשֶׁ֑הָ אֶת־ גֶּ֖בַע וְאֶת־ מִגְרָשֶֽׁהָ׃ (כח) אֶת־ עֲנָתוֹת֙ וְאֶת־ מִגְרָשֶׁ֔הָ וְאֶת־ עַלְמ֖וֹן וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֖ים אַרְבַּֽע׃ (כט) כָּל־ עָרֵ֥י בְנֵֽי־ אַהֲרֹ֖ן הַכֹּֽהֲנִ֑ים שְׁלֹשׁ־ עֶשְׂרֵ֥ה עָרִ֖ים וּמִגְרְשֵׁיהֶֽן׃ (ל) וּלְמִשְׁפְּח֤וֹת בְּנֵֽי־ קְהָת֙ הַלְוִיִּ֔ם הַנּוֹתָרִ֖ים מִבְּנֵ֣י קְהָ֑ת וַֽיְהִי֙ עָרֵ֣י גֽוֹרָלָ֔ם מִמַּטֵּ֖ה אֶפְרָֽיִם׃ (לא) וַיִּתְּנ֨וּ לָהֶ֜ם אֶת־ עִ֨יר מִקְלַ֧ט הָרֹצֵ֛חַ אֶת־ שְׁכֶ֥ם וְאֶת־ מִגְרָשֶׁ֖הָ בְּהַ֣ר אֶפְרָ֑יִם וְאֶת־ גֶּ֖זֶר וְאֶת־ מִגְרָשֶֽׁהָ׃ (לב) וְאֶת־ קִבְצַ֙יִם֙ וְאֶת־ מִגְרָשֶׁ֔הָ וְאֶת־ בֵּ֥ית חוֹרֹ֖ן וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֖ים אַרְבַּֽע׃ (לג) וּמִמַּ֨טֵּה־ דָ֔ן אֶֽת־ אֶלְתְּקֵ֖א וְאֶת־ מִגְרָשֶׁ֑הָ אֶֽת־ גִּבְּת֖וֹן וְאֶת־ מִגְרָשֶֽׁהָ׃ (לד) אֶת־ אַיָּלוֹן֙ וְאֶת־ מִגְרָשֶׁ֔הָ אֶת־ גַּת־ רִמּ֖וֹן וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֖ים אַרְבַּֽע׃ (לה) וּמִֽמַּחֲצִית֙ מַטֵּ֣ה מְנַשֶּׁ֔ה אֶת־ תַּעְנַךְ֙ וְאֶת־ מִגְרָשֶׁ֔הָ וְאֶת־ גַּת־ רִמּ֖וֹן וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֖ים שְׁתָּֽיִם׃ (לו) כָּל־ עָרִ֥ים עֶ֖שֶׂר וּמִגְרְשֵׁיהֶ֑ן לְמִשְׁפְּח֥וֹת בְּנֵֽי־ קְהָ֖ת הַנּוֹתָרִֽים׃ (לז) וְלִבְנֵ֣י גֵרְשׁוֹן֮ מִמִּשְׁפְּחֹ֣ת הַלְוִיִּם֒ מֵחֲצִ֞י מַטֵּ֣ה מְנַשֶּׁ֗ה אֶת־ עִיר֙ מִקְלַ֣ט הָרֹצֵ֔חַ אֶת־ (גלון) גּוֹלָ֤ן בַּבָּשָׁן֙ וְאֶת־ מִגְרָשֶׁ֔הָ וְאֶֽת־ בְּעֶשְׁתְּרָ֖ה וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֖ים שְׁתָּֽיִם׃ (לח) וּמִמַּטֵּ֣ה יִשָּׂשכָ֔ר אֶת־ קִשְׁי֖וֹן וְאֶת־ מִגְרָשֶׁ֑הָ אֶת־ דָּֽבְרַ֖ת וְאֶת־ מִגְרָשֶֽׁהָ׃ (לט) אֶת־ יַרְמוּת֙ וְאֶת־ מִגְרָשֶׁ֔הָ אֶת־ עֵ֥ין גַּנִּ֖ים וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֖ים אַרְבַּֽע׃ (מ) וּמִמַּטֵּ֣ה אָשֵׁ֔ר אֶת־ מִשְׁאָ֖ל וְאֶת־ מִגְרָשֶׁ֑הָ אֶת־ עַבְדּ֖וֹן וְאֶת־ מִגְרָשֶֽׁהָ׃ (מא) אֶת־ חֶלְקָת֙ וְאֶת־ מִגְרָשֶׁ֔הָ וְאֶת־ רְחֹ֖ב וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֖ים אַרְבַּֽע׃ (מב) וּמִמַּטֵּ֨ה נַפְתָּלִ֜י אֶת־ עִ֣יר ׀ מִקְלַ֣ט הָֽרֹצֵ֗חַ אֶת־ קֶ֨דֶשׁ בַּגָּלִ֤יל וְאֶת־ מִגְרָשֶׁ֙הָ֙ וְאֶת־ חַמֹּ֥ת דֹּאר֙ וְאֶת־ מִגְרָשֶׁ֔הָ וְאֶת־ קַרְתָּ֖ן וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֖ים שָׁלֹֽשׁ׃ (מג) כָּל־ עָרֵ֥י הַגֵּרְשֻׁנִּ֖י לְמִשְׁפְּחֹתָ֑ם שְׁלֹשׁ־ עֶשְׂרֵ֥ה עִ֖יר וּמִגְרְשֵׁיהֶֽן׃ (מד) וּלְמִשְׁפְּח֣וֹת בְּנֵֽי־ מְרָרִי֮ הַלְוִיִּ֣ם הַנּוֹתָרִים֒ מֵאֵת֙ מַטֵּ֣ה זְבוּלֻ֔ן אֶֽת־ יָקְנְעָ֖ם וְאֶת־ מִגְרָשֶׁ֑הָ אֶת־ קַרְתָּ֖ה וְאֶת־ מִגְרָשֶֽׁהָ׃ (מה) אֶת־ דִּמְנָה֙ וְאֶת־ מִגְרָשֶׁ֔הָ אֶֽת־ נַהֲלָ֖ל וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֖ים אַרְבַּֽע׃ (מו) וּמִמַּטֵּ֣ה רְאוּבֵ֔ן אֶת־ בֶּ֖צֶר וְאֶת־ מִגְרָשֶׁ֑הָ וְאֶת־ יַ֖הְצָה וְאֶת־ מִגְרָשֶֽׁהָ׃ (מז) אֶת־ קְדֵמוֹת֙ וְאֶת־ מִגְרָשֶׁ֔הָ וְאֶת־ מֵיפָ֖עַת וְאֶת־ מִגְרָשֶׁ֑הָ עָרִ֖ים אַרְבַּֽע׃ (מח) וּמִמַּטֵּה־ גָ֗ד אֶת־ עִיר֙ מִקְלַ֣ט הָרֹצֵ֔חַ אֶת־ רָמֹ֥ת בַּגִּלְעָ֖ד וְאֶת־ מִגְרָשֶׁ֑הָ וְאֶֽת־ מַחֲנַ֖יִם וְאֶת־ מִגְרָשֶֽׁהָ׃ (מט) אֶת־ חֶשְׁבּוֹן֙ וְאֶת־ מִגְרָשֶׁ֔הָ אֶת־ יַעְזֵ֖ר וְאֶת־ מִגְרָשֶׁ֑הָ כָּל־ עָרִ֖ים אַרְבַּֽע׃ (נ) כָּל־ הֶ֨עָרִ֜ים לִבְנֵ֤י מְרָרִי֙ לְמִשְׁפְּחֹתָ֔ם הַנּוֹתָרִ֖ים מִמִּשְׁפְּח֣וֹת הַלְוִיִּ֑ם וַיְהִי֙ גּוֹרָלָ֔ם עָרִ֖ים שְׁתֵּ֥ים עֶשְׂרֵֽה׃
